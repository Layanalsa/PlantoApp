## About

Planto is an iOS application designed to help users take care of their
plants in a simple and organized way. The user adds each plant with its
details, such as the room, the light it needs, the watering days, and the
amount of water. The app then reminds the user when it is time to water.

---

## Features

- Keep all plants in one place
- Watering reminder for the plants
- Choose the light type, the room, and the amount of water
- Mark a plant as watered from the daily list
- Edit or delete any plant at any time
